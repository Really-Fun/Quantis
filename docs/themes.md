# Темы Quantis

Тема описывается одним модулем в `src/quantis/ui/themes/`. Внутри него объект
`THEME` типа `ThemeSpec`. Реестр (`ui/themes/registry.py`) сам находит модули
при запуске, регистрировать ничего не нужно. Тема сразу появляется в
**Настройки → Тема** и в `theme_shots`.

## Как добавить тему

1. Скопируй близкую по духу тему, например `midnight.py` (тёмная) или
   `light.py` (светлая), в новый файл `ui/themes/<id>.py`.
2. Поменяй `id` (уникальный, его пишут в настройки), `label` (название в
   списке) и `order` (место в списке, по возрастанию).
3. Задай цвета в `ThemeColors`. Все поля обязательны, см. таблицу ниже.
4. По желанию настрой фон (`BackdropSpec`), радиусы, шрифты и `extra_qss`.
5. Проверь:

   ```bash
   poetry run pytest tests/test_themes.py
   poetry run python handoff/tools/theme_shots.py --out /tmp/shots --themes <id>
   ```

   Тест `test_validate_is_clean` ловит пустые токены, опечатки в `${…}` и
   остатки неподставленных токенов в итоговом QSS.

Больше ничего трогать не нужно. Если без правки другого файла не обойтись,
значит, тема упёрлась в то, чего система пока не умеет. Тогда расширяй
`ThemeSpec` и шаблоны, а литералы с цветом конкретной темы в виджеты не добавляй.

## ThemeSpec

| Поле | Что задаёт |
|------|------------|
| `id`, `label`, `order` | Идентификатор в настройках, название, место в списке |
| `mode` | `"dark"` или `"light"` (`ThemeSpec.is_light`); сейчас справочное, всё видимое задают токены |
| `colors` | `ThemeColors`, токены цвета |
| `fonts` | `ThemeFonts`: списки семейств для ролей `ui`, `display`, `mono`, `label` |
| `backdrop` | `BackdropSpec`: градиент глубины, виньетка, свечение (`GlowSpec`) |
| `radius`, `radius_control` | Радиусы панелей и кнопок/полей, px |
| `requires_wallpaper` | При выборе темы включить статичные обои |
| `card_style` | `"default"` или `"magazine"` (карточки главной) |
| `glass_blur` | Матовое стекло панелей: глубина размытия фона 0..1; `0` — стекла нет, панели заливаются `surface` |
| `glass_tint` | Тонировка поверх стекла; пусто — `surface`, прозрачнее в 0,6 раза |
| `extra_qss` | QSS только этой темы, см. ниже |
| `aliases` | Старые id из настроек, которые ведут на эту тему |

Свечение фона бывает двух видов: `GlowSpec("cover")` — пятна цвета обложки
плывут по окну (Aurora); `GlowSpec("spots", spots=(GlowSpot(...), ...))` —
неподвижные пятна своих цветов, которые только «дышат» (Glass, Полночь).

## Токены

Всё из `ThemeColors` доступно в QSS-шаблонах и в `extra_qss` как `${имя}`.
Цвет пишется в синтаксисе QSS (`#RRGGBB`, `rgba(r, g, b, a)`), поля `*_rgb`
пишутся тройкой `"r, g, b"`, чтобы подставлять их как `rgba(${ink_rgb}, 0.08)`.

| Токен | Назначение |
|-------|------------|
| `bg` | Сплошной фон окна под градиентами и обоями |
| `ink_rgb` | «Чернила» для полупрозрачных наложений: светлые в тёмной теме, тёмные в светлой |
| `mist_rgb` | Мягкий текст главной (подписи, счётчики) |
| `text` | Основной текст |
| `title` | Крупные заголовки и названия |
| `text_dim` | Вторичный текст: исполнитель, заголовки колонок |
| `text_meta` | Мелкий служебный текст: время, статусы |
| `text_soft` | Текст кнопок-«призраков», значки кнопок окна |
| `tint`, `tint_rgb`, `tint_hover` | Собственный цвет темы: чипы, фокус, кнопки |
| `on_tint` | Текст на заливке `tint` |
| `hl_rgb` | Подсветка: кикеры, заголовки разделов, чекбоксы, ссылки-действия |
| `accent_fallback` | Акцент, пока нет обложки (потом акцент берётся из обложки) |
| `surface` | Панели: плеер, «Сейчас играет», боковое меню |
| `chip_bg`, `field_bg` | Фон чипов и полей ввода |
| `handle` | Ручки ползунков |
| `popup_bg`, `popup_border`, `list_bg` | Меню, диалоги, выпадающие списки |

Производные токены считаются сами:

| Токен | Откуда |
|-------|--------|
| `accent_fallback_rgb` | Тройка из `accent_fallback` |
| `font_ui`, `font_display`, `font_mono`, `font_label` | `font-family` из `ThemeFonts` |
| `radius`, `radius_control` | Значения полей с `px` |
| `radius_capsule` | Скругление плеера-капсулы: `26px`, у темы без скруглений (`radius=0`) — `0px` |
| `panel_bg` | Фон стеклянных панелей: `transparent`, если у темы есть стекло, иначе `surface` |

## Шрифты

`ThemeFonts.display` — только для крупных заголовков: название трека на
сцене и в панели «Сейчас», заголовки секций и плейлиста, «Фон», «Дальше».
Весь остальной интерфейс — `ui`. Если у темы `display` не задан отдельно,
заголовки просто используют шрифт интерфейса. Aurora и Glass: Manrope для
интерфейса и Unbounded для заголовков (оба встроены в `assets/fonts`).

## Стекло и фон окна

Фон всего окна рисует `BackdropCompositor` (цвета трека, обложка, своя
картинка или клип; затемнение для читаемости). Панели с матовым стеклом
подключаются одной строкой:

```python
install_glass(widget, "QFrame#myPanel")
```

Под виджетом рисуется размытая копия фона, поверх — `glass_tint`. Радиус и
толщину рамки стекло берёт из итогового QSS темы для этого селектора, так
что в QSS у панели должен быть `background: ${panel_bg}`. Плагины могут
подключать свои панели так же.

Фиолетовый Aurora и прочие цвета конкретной темы живут только в её
`ThemeColors`. Тесты проверяют, что за пределами `ui/themes/` нет ни id тем, ни
этого фиолетового.

## Как собирается QSS и что такое `extra_qss`

Общие шаблоны лежат в `src/quantis/styles/templates/*.qss`, один набор на все
темы. `ui/themes/qss.py` склеивает их в фиксированном порядке и подставляет
токены через `string.Template` (`${…}`, потому что в QSS и так полно фигурных
скобок). Каждый селектор в шаблонах задан ровно один раз, за этим следит тест.

`extra_qss` — это QSS, который нужен только одной теме. Токены в нём тоже
работают. Он **сливается** с шаблоном по селекторам, а не дописывается в конец:

- если такой селектор есть в шаблоне, свойства темы дополняют и перекрывают
  его свойства в том же блоке;
- новые селекторы идут в конец.

В итоговом QSS каждый селектор встречается один раз, поэтому порядок правил и
специфичность не преподносят сюрпризов. Результат кэшируется по id темы.

```python
EXTRA_QSS = """
#searchInput {
    border-radius: 14px;                                     /* перекрывает шаблон */
    selection-background-color: rgba(${tint_rgb}, 0.35);     /* дополняет */
}
"""
```

В `extra_qss` клади то, что отличает тему по форме (радиусы, рамки,
отступы). Если правило просто повторяет шаблон с другим цветом, лучше завести
токен.
